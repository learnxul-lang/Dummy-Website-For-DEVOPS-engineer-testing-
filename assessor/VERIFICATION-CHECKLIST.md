# Verification Checklist

- [ ] Inspect commit history and commit messages.
- [ ] Confirm feature development occurred on a separate branch.
- [ ] Inspect the Pull Request and merge record.
- [ ] Confirm .env or any assessment secret does not appear in repository history.
- [ ] Confirm main contains the approved System Status feature.
- [ ] Confirm the candidate incorporated the supplied remote update.
- [ ] Verify the live Vercel deployment.
- [ ] Confirm Version 1.1 produced a later deployment.
- [ ] Ask the candidate to explain working directory, staging area, local repository and remote repository.
- [ ] Confirm the candidate can explain Git versus GitHub and the deployment flow.
