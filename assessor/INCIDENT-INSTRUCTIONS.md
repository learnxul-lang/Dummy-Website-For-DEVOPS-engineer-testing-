# Collaboration Incident

## Candidate instruction
Another developer has updated the remote repository while you were working locally. Their change is required for the next release.

Synchronise your local environment with the latest remote work without losing your own work. Confirm that your local repository contains both the required remote change and your work.

## Assessor setup
Issue this only after the candidate has started feature work.

### Standard version
Make a small remote change to a different part of the project.

### Advanced version
Modify the same line or nearby content changed by the candidate so that integration requires conflict resolution.

Do not tell the candidate which Git command to use. Assess whether they inspect repository state, preserve work, integrate correctly and verify the result.
