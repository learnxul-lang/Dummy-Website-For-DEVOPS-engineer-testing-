# Assessor Guide

## Recommended conditions
- Level: Junior DevOps Engineer / DevOps Trainee
- Duration: 2–3 hours
- Total: 100 marks
- Pass mark: 70%
- Production branch: main
- Primary workflow: command-line Git, GitHub and Vercel

## Assessment philosophy
Describe required outcomes rather than giving the candidate exact commands. The purpose is to test practical understanding, repository state awareness, troubleshooting and collaboration workflow.

## Before starting
Ensure the candidate has:
- Git installed and a terminal.
- GitHub access.
- Permission to work with the assigned assessment repository.
- Vercel access.


## During assessment
Inspect the repository rather than relying only on screenshots. Ask the candidate to explain where their changes currently exist: working directory, staging area, local history, remote branch, merged production branch or deployed application.

Issue the collaboration incident only after the candidate has created/pushed feature work. See INCIDENT-INSTRUCTIONS.md.
